## 6. 凍結裁定（D12 outline vs Swift/golden）

D12 是提案；依任務規則，Swift 實際行為 + 既有 golden 優先。以下是本 revision 的裁定，Kotlin B6
必須照此實作，不得照 outline 的文字。

1. **CCR-D12-1 missing priority 是中文句。** Outline/README 寫上游英文
   `SendToAgent requires priority ...`；Swift 回
   `SendToAgent 需要 priority：true 表示立即唤醒，false 表示等对方下一个回合。`。裁定：凍結中文句，
   同步修正 README §1.1；`team.md` §2.1/§7。
2. **CCR-D12-2 target-not-found 是中文 `「」` + `", "`。** Outline 的
   `agent not found: "<x>". Available bots: <list>.` 不存在於 Swift。裁定：凍結
   `没有找到队友「<x>」。可选的 Bot：<list>。`，list 用 `", "`，排除 caller/hidden。
3. **CCR-D12-3 hidden Bots 可按 id/name 命中。** Outline 說 hidden 不是 target；Swift 只把它從
   廣告/available list 排除，resolve 仍用全名冊。裁定：hidden 可達，但不可見；fixture
   `send-hidden-target-by-name` 證明。
4. **CCR-D12-4 `requestId = agent:<callId>`。** Outline 的「requestId 取調用 id」不精確；
   bare callId 只是 pre-WP4 兼容 lookup。裁定：writer 只寫 prefixed form，replay 回 prefixed。
5. **CCR-D12-5 CreateTeammate 的長度是 UTF-16 units。** `name.utf16.count <= 60`；description
   截 300 UTF-16 units 且不切 surrogate。Kotlin 用 UTF-16 `String.length`，不是 scalar。
6. **CCR-D12-6 沒有 held-full。** Outline 列的 `held-full` 在 Swift/v2 held inbox 不存在；
   enqueue 失敗一律 `execution_failed` 加 §2.6/§2.10 的精確句。不得新增 error code。
7. **CCR-D12-7 task status 是 `stopped`，不是 `cancelled`。** Swift 另有 `waiting_approval`/
   `denied`；`cancelled` 是 routine 的值。裁定：凍結
   `running|stopping|waiting_approval|completed|failed|stopped|interrupted|denied`；修正
   `tool-contracts.md` §4.4。
8. **CCR-D12-8 `persistedTask.createdAt` 是 snapshot write time。** Swift 每次 persist 都寫
   `now()`，不是建立時間。裁定：照 Swift；要穩定 createdAt 需新欄位/新 PC。
9. **CCR-D12-9 completed wake 沒有 durable marker。** Outline 說 wake marker 是 snapshot 的
   一部分、exactly once；Swift 只為 interrupted/denied 設 `wakeDelivered`。completed record
   與 wake 之間 crash 會失去 wake，restore 不重放。裁定：照 Swift，記錄 gap；owner 待決是否
   加 marker（新 PC）。
10. **CCR-D12-10 `Task.timeout_ms` 不殺 turn。** 它是 snapshot / `<task_contract>` budget /
    verifier budget；只有 `AwaitTask.timeout_ms` 限制等待。裁定：照 §9。
11. **CCR-D12-11 `task.stop_requested` 沒有 `stop:<taskId>` eventId。** D13 `tool-contracts.md`
    §4.3 的 `stop:<taskId>` 是錯的；Swift 用 generated id，`settled:<taskId>` 才固定。裁定：
    修正文件。
12. **CCR-D12-12 legacy task 無 `persistedTask` 是 ignored。** D12 允許 interrupted 或 ignored；
    Swift restore 直接跳過，`AwaitTask`/`StopSubagent` 回 `unknown task`。裁定：ignored；
    terminal `task.settled` widget row 仍投影。
13. **CCR-D12-13 `waiting_approval` 是 AwaitTask 的 terminal，但跨 restart 保留。** 不映射
    interrupted；restore 不自動 reconcile，host 必須在 recovery 路徑呼叫

14. **CCR-D12-14 hidden wake 不能 `SendToUser`。** Swift 的 `hiddenTextSessions` 拒絕 hidden

## 7. Kotlin B6 陷阱（依賴 B7a agent-comm row model）

1. **B7a 先於 B6 的 row model。** B6 的 outbound/inbound 寫入依賴 B7a 的
   `AgentCommRow(direction,rowID,threadID,requestID,fromAgent,toAgent,hop,callID,turn,
   replyEntryID,error,delivery,status,title)` 與 `t<turn>u` 分配器；不要讓 B6 自己另造一個
   row schema。row id/thread id 的 SHA-256 輸入含 NUL，Kotlin 必須用 UTF-8 bytes 且小寫 hex。
2. **UTF-16 邊界。** `name` 60、description 300、held reply 1200 都以 UTF-16 units 計；
   Kotlin `String.length` 與 `substring` 要避免切 surrogate pair（Swift 用 grapheme 邊界）。
   Python/validator 與 Swift fixture 已凍結 60/61、300/301、1200/1300 的邊界。
3. **held inbox 是 v2 的既有模型。** `agent-held` item 的 `requestId`/`threadId`/`fromAgent*`/
   `title`/`text`/`createdAt`/`state` 必須逐字對上 `held-inbox-item.schema.json`；B6 不要把
   held reply 寫成 `ui.send_to_user`，也不要把 queued message 寫成 task 或 notice。
4. **task row 與 widget。** `task.*` events 由 B7a 投影成 task widget；B6 只寫 record/
   `persistedTask`，不要另寫 UI row。`persistedTask` 是 `data` 的 child object，不是頂層欄位。
5. **incarnation/epoch。** 任務 owner 綁 `parentIncarnation`；B6 的 `AwaitTask`/`StopSubagent`
   必須用同一個已認領 principal，不能每次重新 `issueSession`（會 rotate incarnation，live task
   變成 unauthorized）。erasure epoch 切換後只有 chat parent 的 successor 可讀/停；task/routine
   parent 留在原 session。
6. **300 s 與 request id。** `SendToAgent` 的 300,000 ms 是 caller wait，不是 target cancel；
   task 的 request id 前綴（`task-turn:`/`task-settled:`/`task-interrupted:`）直接決定 hidden/
   origin/memory trust，B6 不得用隨機 id 或 `agent:` 前綴代替。
7. **同一份錯誤句。** B6 的 model-visible 文字必須與 `team-cases`/`task-cases` 的 `message`
   完全相同（含全形標點、`「」`、`→`、引號）；不要把 outline 的英文句或 D13 的 `cancelled`
   帶進來。
