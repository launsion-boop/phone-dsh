## 2. 契約 delta

| 項目 | Before → After／依據條款 |
| --- | --- |
| `interaction.sheet.pageDetents` 列數 | 13 → 20。新增 `settings`、`modelProvider`、`configuration`、`runtime`、`commandResult`、`deviceConnection`、`automation`，全部 `detents: default`，出處為各自 `.homeSheetChrome()` 行（`ChatPage.swift:496/520/524/532/538/543`、`SettingsPage.swift:117`）。 |
| `interaction.sheet.pageDetents[].note` | 新可選字串（≤300）；目前只有 `chatSessions` 使用：debug-only，只由 `ChatPage.swift:805` 的 DEBUG 鉤子打開。 |
| `.presentationDetents` 站點計數 | 仍是 13；規則 12 只把它與「非 default 列數」比對，不再與全部 `pageDetents` 列數比對。 |
| default 列的來源約束 | 新增：`detents == defaultDetents` 的列必須錨在 `.homeSheetChrome()` 行，且該行所屬 `.sheet` body 不得含 `.presentationDetents(`；非 default 列必須錨在 `.presentationDetents(` 行。 |
| `pages/turn-usage.json` | 新 chrome 契約：title 本輪用量；七列 缓存命中/未缓存输入/缓存读取/缓存写入/输出/其中推理/合计，逐列 provenance 與 condition，`valueExpr` 記錄 Swift 實際格式（`nativePercent` 與 `"\(value) tok"`）；`nativeCompactTokens` 只屬回合尾部用量按鈕（`NativeMessageActions.swift:50`），不是本 sheet 的列格式。 |
| `spec/platform/whitelist.json` | 新增 `platform.disclosure-state-announcement`；`divergence_class: os-forced`，`spec_ref: spec/ui/v1/interaction.md §7`，`evidence_level: emulator-probe`。 |
| `interaction.md` §2/§7 | §2 更新站點計數規則、`chatSessions` debug-only 一句；§7 新增無障礙第 7 條，指向平台白名單。 |
| README §1 | 新增 `NativeTurnUsageDetails` 列（回合尾部用量 → medium sheet，契約 `turn-usage.json`）；同時把 §1.1 表格中的空行併回、把兩段 page-structure 規則併成一行，維持 345 行上限。 |

## 3. 相容性與發佈

| Producer → Consumer | 支援／拒絕方式及理由；對應測試 |
| --- | --- |
| old Android → new tokens | 舊生成器讀 `pageDetents` 的 `id`/`detents`，忽略 `note` 與新 id；13 個顯式 id 的 detent 不變，所以建置與既有行為不變。 |
| new Android → old tokens | 不在支援矩陣：`tokens.json` 與 App 同倉，`generateUiTokens` 在缺 `interaction.sheet` 時已 fail-loud。舊 13 列檔案沒有新 id，`SheetDetents.forPage` 會回 default；但本 repo 不會產生這組合。 |
| new → new | 本變更；生成物 `TokenSheetPageDetent` 多一個 nullable `note`，`SheetDetents` 的查表介面不變。 |
| persisted old data → new／rollback | 不適用：tokens 是建置期輸入，不落盤到使用者裝置。 |

- 版本決定依據 `spec/ui/v1/schema/tokens.schema.json` 的 version 1 與「新增可選欄位、放寬列數」規則；
  沒有新 detent 值，沒有 wire/API 變更。
- Android follow-up 不需要 adapter：`sheetPageIdOf` 目前把 `Automation`/`Configuration`/`Settings`/
  `ModelProvider`/`Runtime`/`DeviceConnection`/`CommandResult` 全映射到 `defaultDetents.spec`；新 id 到位後
  應改讀各 id（見 §4）。舊 id 字串（`default`）仍是合法 detent 值，不會因新 id 失效。
