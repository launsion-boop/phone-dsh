## Debug-harness artifact (do not measure it as page UI)

Most shots are a `fullScreenCover` presented by `PreviewScreen.body`
(`NativeShell.swift:759`). That cover draws a 44 × 44 **blue-grey ✕ circle at
the top-left**. It is not part of the page:

* Sessions, Files, Workspace, Schedules, Settings subpages: ✕ floats above the
  page, top-left.
* Settings / chat previews: it overlaps the page's own top-left control (the
  glass 完成 button, the sidebar icon).
* `ios-chat-default.png` uses `-uiPreview sample`, which renders the real
  `NativeShell` root with **no cover**, so it has no ✕ and is the cleanest shot
  of the chat header.

## Reproduce

```bash
bash android/tools/ios-baseline-capture.sh --capture-copy
```

The script recreates the device, pins appearance/content size/status bar,
creates the one-constant copy, builds, installs the app fresh for every shot,
writes the PNGs and `conditions.txt` here, and prints the unreachable list.
Without `--capture-copy` it builds HEAD and fails with the error quoted at the
top — that is the intended strict behaviour until the baseline is fixed.

Validated end-to-end on 2026-10-31: `--capture-copy` → exit 0, 26 PNGs +
`conditions.txt`; the static pages are pixel-identical to the files in this
directory (e.g. `ios-settings.png`: 0 differing pixels). `ios-chat-default.png`
differs run-to-run because it boots the real host and installs the sample
thread; both runs show the same layout and states.

## Build-failure receipt

```
$ xcodebuild -project examples/probe-app/PhoneDSHProbe.xcodeproj \
    -scheme PhoneDSHProbe -configuration Debug -sdk iphonesimulator \
    -destination 'generic/platform=iOS Simulator' \
    -derivedDataPath <tmp> build CODE_SIGNING_ALLOWED=NO
…
examples/probe-app/ProbeKit/Office/OfficePresenter.swift:84:77: error: type 'ChatHostConfiguration' has no member 'defaultOfficeInteractionTimeout'
            try? await Task.sleep(nanoseconds: UInt64(ChatHostConfiguration.defaultOfficeInteractionTimeout * 1_000_000_000))
…
** BUILD FAILED **
```

`ChatHostConfiguration` at HEAD declares
`workspaceDirectoryName`, `workerPlaceholderKey`, `defaultDrainDeadline`,
`defaultHelloTimeout`, `defaultBootTimeout`, `workspaceRoot(documents:)`,
`modelHostRule(for:)`, `make(…)` — and no office timeout. The capture copy adds
exactly that one member.
