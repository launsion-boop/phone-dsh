# 功能测试计划（原生版）— 2026-10-28

## 目的

给原生版定义一轮可重复、可勾选的功能验收：每一屏、每一个可点的入口，都有明确的预期结果和验证方法。测试分三层：

1. **截图层**（模拟器 + `-uiPreview`，无需真模型）：每屏的版式、空态、错误态、长内容。
2. **交互层**（模拟器/真机，无需真模型）：抽屉、导航、设置项持久化、会话切换、停止/重试。
3. **真实层**（真机 + 真 API Key）：真实回合、流式、工具行、文件产出、后台保活、PDF/图片预览。

## 环境与方法

```bash
# 截图层：直达某一屏（模拟器，仅 Debug 构建）
xcrun simctl launch <UDID> dev.phone-dsh.probe -uiPreview <name>
xcrun simctl io <UDID> screenshot /tmp/ui-shots/<name>.png

# 交互层：状态日志（真机）
xcrun devicectl device copy from --device <UDID> \
  --domain-type appDataContainer --domain-identifier dev.phone-dsh.probe \
  --source Documents/chat-status.log --destination /tmp/chat-status.log
```

`-uiPreview` 可用名：`settings`、`settings.model`、`settings.search`、`settings.network`、
`settings.plugins`、`settings.about`、`settings.runtime`、`sessions`、`sessions.schedules`、
`workspace`、`workspace.files`、`configuration`、`chat.assistant`、`chat.failed`、`chat.queued`、
`chat.long`、`chat.draft`、`chat.permission`、`code.block`、`sessions.many`、`sessions.empty`、
`sessions.nothing`、`sessions.ungrouped`、`sessions.error`。

## 本轮已修复（对应上面的用例）

- A3：抽屉点会话从任意状态可打开（停机自动启动、parked 自动恢复、运行中先停止）。
- A5：resume 后按 `session/list` 对账 `turnRunning`，清掉发送/排队标签。
- B1/B5：标签在首个活动后清除（不再只等助手正文）。
- B3：修复时间线每行重算整表（O(n²)）导致的卡顿。
- B4：停止按钮去掉多余文案；3 秒无终态则本地结束并提示。
- B11：预览路径归一化（`/dsh/workspace/…`、`file://`、`sandbox:`、`./`），列表未命中先刷新、再按唯一文件名匹配，仍缺则提示稍后重试；回合进行中每 2 秒刷新文件列表。
- C4：phone profile 重新启用 `session-title-llm`；本地首句摘要兜底。
- F6：窗口锁定浅色，避免系统深色下黑底。
