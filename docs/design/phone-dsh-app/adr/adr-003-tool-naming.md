# ADR-3：内部点号工具名与模型侧名称分离

- 日期：2026-11-03
- 状态：已决定，待实现验收

## 背景

现有 DSH 通过 `phone` 分发 `github.pull.get` 等点号名称。原生 Main 的模型协议可能只接受字母、数字、下划线和连字符，不能假设两种调用方使用相同名称。

## 决定

内部稳定名称继续使用 `github.*`、`gmail.*`。模型侧由 `ToolNameCodec` 映射为 `github_pull_get` 等 `[a-zA-Z0-9_-]` 形式，长度不超过 64。映射必须可逆，重复或冲突在启动时失败。

## 后果

- DSH 保持现有调用兼容。
- 原生 Main 不依赖特定 Provider 对点号工具名的支持。
- 模型看到的名称稳定，内部审计统一使用点号名。

## 验证

- 双向映射、非法字符、长度上限、冲突检测。
- DSH 的 `phone github.pull.get` 与原生 Main 的 `github_pull_get` 落到同一实现。
