# PhoneDSH App 每屏状态矩阵

- 版本：v0.2 · 人工门①评审稿（五 Tab 动态结构）
- 目的：在进入视觉前，确保每屏都知道“未配置、没有数据、没有设备、没有权限、执行失败、后台中断时怎么办”。

## 1. 通用规则

- **空不等于失败**：没有内容时解释原因和下一步。
- **未配置不等于不可用**：Personal Agent 未配置不能阻塞 DSH。
- **部分可用不等于空**：日记或 Memory 缺材料时显示覆盖缺口，不能写“什么都没有”。
- **历史永远可读**：引擎失败、设备离线或 Provider 不可用不阻断本地历史、文件和设置。
- **动作必须可恢复**：失败提供重试、对账、修改配置或取消；不可恢复动作明确后果。
- **状态不只靠颜色**：灰阶原型也用文本、图标、位置和形状区分。
- **Mock 不等于真实**：所有演示回执、发送和推进都标明 Mock。

## 2. 全局状态

| 状态 | 全局表现 | 允许操作 | 恢复 |
| --- | --- | --- | --- |
| agentNeedsApiKey | Chat 显示配置引导，AI日记未出现，DSH 可用 | DSH、发现、个人设置 | 配置 API key 并进入命名 |
| agentNeedsNaming | Provider 已配置，等待 Agent 名或主人称呼 | 返回修改、暂不连接硬件 | 完成命名后出现 AI日记 |
| starting | 顶部“正在准备本地引擎”，新任务暂未开放 | 历史、Provider 设置 | 等待或打开设置 |
| running | 顶部“本地运行” | 全部已授权功能 | — |
| parked | 顶部“后台已暂停”，显示最近检查点 | 历史、恢复、取消 | 回前台恢复 |
| failed | 顶部“引擎需要处理” | 历史、设置、重置后恢复 | 打开恢复页，不自动清空工作区 |
| device offline | 设备图标离线，实时 ASR 行消失 | 文字任务、历史、重新配对 | 重连并核对设备 epoch |
| provider unavailable | 显示具体 Provider 不可用，不声称离机 | 本地历史、切换 Provider | 修改端点/密钥或稍后重试 |
| permission denied | 对应 BLE/麦克风/通知入口显示系统权限状态 | 其他不依赖权限的功能 | 去系统设置或稍后授权 |

## 3. Personal Agent 与首次配置

| 屏幕 | 默认 | 加载/空 | 未配置/离线 | 错误/受阻 | 下一步 |
| --- | --- | --- | --- | --- | --- |
| #chat（未配置） | 价值说明、配置按钮、DSH 次入口 | 不显示伪造的个性化历史 | 无 key、无设备均可进入配置或返回 DSH | Provider 失败仍可回 DSH | 配置 key 或先去 DSH |
| #agent-setup | Provider、数据路径、密钥位置 | 未选 Provider 时主按钮禁用 | 离线仍可填写，但不伪造验证成功 | 验证失败保留输入，可修改重试 | Mock 验证后进入 Agent 名 |
| #agent-name | Agent 名输入与建议 | 空白禁用完成 | 可返回改 Provider | 名称冲突/超长给具体原因 | 进入主人称呼 |
| #owner-name | 主人称呼与本地说明 | 空白可给默认或禁用 | 不强制登录，不连接硬件 | 保存失败保留上一步 | 完成后 Chat 与 AI日记出现 |
| #chat（已配置） | 个性化消息、当前设备、委派卡、Composer | 首次显示建议；发送中显示过程 | 无设备仍可用文字；引擎失败禁新任务 | 发送失败可重试；未知不自动重试 | 打开任务、连接设备或恢复 |
| 实时 ASR 行 | 最新 FINAL 与来源设备 | 无新句时收起 | 未配对/离线不显示 | ASR 失败显示缺口，不伪造文字 | 点击到日记对应证据 |

## 4. DSH 与任务

| 屏幕 | 默认 | 加载/空 | 离线/未连接 | 失败/未知 | 后台/权限 | 下一步 |
| --- | --- | --- | --- | --- | --- | --- |
| #dsh | 当前 PhoneDSH 原生会话主页、消息流、TaskRun、会话抽屉 | 首次显示“新会话 / 引擎还没启动”和启动按钮；无历史时可从抽屉看工作区 | Personal Agent 未配置仍可用；离线读本地会话与产物 | 失败与 outcome_unknown 分组显示 | parked 显示最后检查点 | 启动引擎、继续会话、打开详情、恢复或对账 |
| #task-hardware-plan | 步骤、等待、产物与成本 | 初始化/加载历史 | 离线可查看已有内容 | 失败可恢复；未知先对账；取消按回执 | waitingApproval 保持等待 | 打开审批、产物或恢复 |
| #approval-feishu | 目标、正文、范围、成本、后果 | 准备动作并冻结预览 | Provider 离线仍可拒绝，不能提交 | 过期/撤权不可批准；未知先对账 | 离开页面后仍需重新核权 | 允许一次或拒绝；无默认永久授权 |

## 6. 发现、个人与 Memory

| 屏幕 | 默认 | 加载/空 | 离线/未连接 | 失败/未知 | 后台/权限 | 下一步 |
| --- | --- | --- | --- | --- | --- | --- |
| #discover | 硬件、连接器、服务应用目录 | 无已安装服务只显示推荐与条件 | 各项显示真实离线而非 connected | 未接入能力打开条件说明，不模拟成功 | 权限不足只关闭对应工具 | 打开设备、连接器或条件说明 |
| #personal | Agent 名、Provider、Memory、隐私、设置 | 未配置时给配置入口 | 无账号也可配置本地个人层 | Provider 失败可重试/切换；usage unknown 显示未知 | 密钥只写 Keychain，页面不回显 | 修改配置、进入 Memory 或隐私 |
| #memory | 搜索、待确认、关于我、工作进展 | 首次无记忆给“去 Chat”；加载骨架 | 本地数据可读；新整理暂停 | 读取失败保留旧内容并允许重试 | 候选未经确认不能用于回答 | 搜索、打开条目、确认或修改 |
| #memory-local-first | 正文、状态、来源、修订、操作 | 加载条目与版本 | 来源缺失显示受限，不虚构 | 版本冲突重新读取；遗忘清理范围如实显示 | 来源撤回后停止用于新回答 | 确认、修改、驳回、归档、忘记与撤销 |
| #privacy | 本地数据、Provider 路径、导出、遗忘 | 统计加载 | 无 Provider 也可管理本地数据 | 导出失败不生成空文件；遗忘失败可重试 | 密钥永不展示；高敏操作二次确认 | 导出、暂停录音、管理遗忘 |

## 8. Mock 场景开关

| 场景 | 主要检查 |
| --- | --- |
| 未配置 | 默认 DSH；Personal Agent 显示 needsApiKey；AI日记未出现；可先配置或直接用 DSH |
| 默认（已配置） | Agent 已有名字、AI日记出现、一个 BLE 设备、运行中任务、待确认记忆 |
| 无设备 | 未配对状态、Chat 仍可用、实时 ASR 行消失、日记仍有历史 |
| 离线 | 本地历史可读、设备不能控制、Provider 提交被阻止、可重试/对账 |
| 引擎失败 | 新任务禁用、设置与恢复入口存在、历史与产物仍可读 |
| 空数据 | 无任务、无日记、无记忆候选，空态解释与下一步完整 |

场景切换只改变 Mock 视图，不宣称测试了真实后台、BLE、Provider 或文件系统。
