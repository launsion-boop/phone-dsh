# Stored pixel baselines

These PNGs are generated by `android/tools/screenshot-capture.sh` from the
**current Android implementation** on the pinned emulator, and compared by
`android/tools/test_screenshot_compare.py`.

* **能 / can prove:** 从今以后 UI 改动导致的视觉回归会被抓住（像素 diff）。
  A UI change that moves pixels is caught by a pixel diff.
* **不能 / cannot prove:** 证明与 iOS 基线视觉一致。基线由**当前 Android 实现**生成，所以它是「防回归」而不是「parity 证明」。
  It does not prove visual parity with the iOS baseline. It is a regression gate,
  not a parity proof.

Full rationale (capture chain, fixed conditions, threshold, coverage gaps):
[`android/lib/src/androidTest/README.md`](../../androidTest/README.md).

`metrics.txt` is the conditions receipt for the last capture: size, dpi,
density, fontScale, scaledDensity, locale, theme and the font-scale probe's
measured text box height.

Do not hand-edit these files. Re-capture with `--update` and review the diff.
